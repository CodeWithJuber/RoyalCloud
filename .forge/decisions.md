# Decisions

Append-only — supersede an old choice with a NEW entry (`forge decide`), never an edit.

- **D-0001** (2026-09-04): web/DESIGN.md (new) is the design authority for the Next.js app; root DESIGN.md stays Astro-only — the root doc names Astro files that do not exist in web/, and the owner asked to stop relying on it and document the current violet/gold Astryx theme from real sources
- **D-0002** (2026-09-04): Term-only price labels ('per month, billed monthly/yearly') replace 'renews at the same rate' in PlanCards and PlanFinder — the plan catalog carries no renewal data, so a renewal claim would be invented; the owner chose not to add a renewal field
- **D-0003** (2026-09-04): Light-section card hover hairline is violet-only (accent to #9b85ff); gold stays reserved for conversion CTAs and the popular plan card — keeps the single-conversion-colour rule from theme/royal.theme.ts
- **D-0004** (2026-09-04): web/package.json check runs 'next typegen' before tsc — LayoutProps is a Next 16 generated global type in .next/types, so a fresh checkout failed tsc (TS2304) before any build; typegen makes the gate deterministic
- **D-0005** (2026-09-04): Section anchors come from lib/section-ids (explicit content id wins, else per-type default, -2/-3 suffixes) and SectionRenderer passes them as id props; PageView computes them once — avoids adding id fields to every CMS block
- **D-0006** (2026-09-04): Hero intent chips render only on the gradient (home + landing) hero; product heroes keep the compact 'Help me choose' link with the page's product pre-answered — product heroes are height-constrained on phones (844px above-fold rule) and already name their product
- **D-0007** (2026-09-04): Plan finder budget bands are derived from each deck's real tier prices (floor(n-1)/3 and round(2(n-1)/3) of the sorted price ladder + 'No fixed budget'); a cap never names a price that does not exist, and clamping is announced as 'Closest match within your budget'
- **D-0008** (2026-09-04): Finder 'online store' maps to the Managed WordPress deck (WooCommerce), 'hosting for my clients' to reseller, vps+managed to the managed cloud deck; builds with a single sensible stack (reseller) skip the stack step
- **D-0009** (2026-09-04): Comparison table: the 'Most popular' header flag is a white pill with violet text (gold removed from a non-CTA element); phone collapse is a data-expanded attribute + CSS gated on html[data-js] so no-JS renders every row; Astryx Collapsible is not used inside the table because its wrapper element breaks table semantics
- **D-0010** (2026-09-04): Comparison tooltips appear only when a deck highlight title matches the row label (lib/feature-groups tooltipFor) — no explanatory copy is invented; rows are grouped by a deterministic keyword map and never re-indexed
- **D-0011** (2026-09-04): Count-up animates only stat strings that are a plain leading number with a harmless suffix (%, x, +, /10…) and value ≥ 2; ratios like 24/7, ranges, labels and 1M+ stay static; SSR prints the final value and the animation starts only from an IntersectionObserver callback — no hydration drift, nothing invented
- **D-0012** (2026-09-04): Testimonials carousel is a CSS scroll-snap rail with prev/next/dots and a live 'n of N'; no autoplay (WCAG 2.2.2 and the owner's no-autoplay rule); controls render only when the rail overflows; per-page inline testimonial/FAQ items are now forwarded by SectionRenderer (30 landing pages previously showed the global set)
- **D-0013** (2026-09-04): One-click deploy tabs are driven by a static lib/deploy-catalog keyed by the names content already authors (no CMS schema change); descriptions/links exist only where copied verbatim from a deck highlight or the page's own copy (test-enforced), so the CyberPanel VPS page gets OS/panel/app tabs while OS-only pages keep the flat chip row
- **D-0014** (2026-09-04): Product sub-nav (Plans · Features · Compare · FAQ) renders only on pages with both a pricing deck and a comparison table, sits right under the hero via SectionRenderer's after-slot, and its 'From $X/mo' CTA anchors to #pricing (the plan table) rather than jumping straight to WHMCS checkout — the visitor picks a tier first; phones keep MobileCtaBar instead
- **D-0015** (2026-09-04): Feature cards accept optional metric/metricLabel (schema + Decap + renderer in one commit) rendered only when authored; the only seeded figure is shared-hosting's 15x, which the site's own stats band already states; the previously unused variant:tiles is now honoured for the four landing pages that author it
- **D-0016** (2026-09-04): Scrollspy picks the section that contains the line just under the sticky chrome (header + sub-nav, re-read per callback) instead of the first intersecting section — adjacent sections both intersect the band, and the sub-nav publishes its height after mount; the probe also surfaced pre-existing 390px overflow (domain-search input min-width:auto, no-wrap trust tiles, 176px logo in a 390px header) fixed in the same commit
